# 学习日课

每天的学习待办清单，在这里打勾。免费托管在 GitHub Pages，不需要服务器；输入密码后，勾选会直接提交到这个仓库，Claude 每天早上 9 点读取真实勾选，安排当天的任务。

## 怎么用

- **看任务**：打开网站就是今天的清单，左右箭头切换日期。不解锁也能看。
- **打勾**：点右上角「解锁」输入密码（可以记住 30 天），之后勾选自动保存，每次是一次提交。
- **自己加一条**：底部输入框添加；自己加的可以删，Claude 写的不能删。
- **离线也能勾**：没网或没解锁时，改动先存在这台设备上，解锁或联网后自动提交。
- **本地文件**：网页打不开电脑上的文件，所以课程资料提供「复制本地路径」，在 Finder 按 ⌘⇧G 粘贴即可。

## 密码是怎么工作的

和科研日志网站一样：第一次在「解锁 → 去设置」里粘贴一个**只授权本仓库**的细粒度令牌（Contents 读写），再设一个密码。令牌在浏览器里用密码加密（PBKDF2 60 万次 + AES-256-GCM），只把加密结果存为 `data/vault.json`。

- 密码不会被发送或保存到任何地方；加密文件在公开仓库里，所以密码别太简单。
- 令牌万一泄露，到 GitHub 删除令牌，再打开 `#/setup` 重新设置。令牌最长一年，过期后同样重新设置。

## 数据格式

每天一个文件 `data/days/YYYY-MM-DD.json`，没有文件就表示那天没有任务。

```json
{
  "date": "2026-10-28",
  "headline": "今天的一两句说明",
  "progress": "进度条文字（等宽显示）",
  "updatedAt": "ISO 时间",
  "items": [
    {
      "id": "L01-slides",            // 当天内唯一
      "text": "看完第 1 讲课件",
      "detail": "补充说明",
      "group": "CS329Z",             // 同组的放在一起，按首次出现排序
      "mins": 45,
      "done": false,
      "doneAt": null,                 // 打勾时间，网页写入
      "source": "claude",            // "me" 表示自己在网页上加的
      "carried": true,                // 可选：从前一天顺延
      "ref": "cs329z:L01-slides",     // 可选：对应自学路线里的条目
      "links": [{ "label": "课程主页", "url": "https://…" }],
      "local": "讲次/L01*/*L01_课件*", // 可选：课程文件夹里的相对路径
      "howto": "没有链接时显示的打开方式"
    }
  ]
}
```

其他字段（如 `plannedBy`、`englishPlan`）原样保留。网页保存时会先取仓库里最新的文件，再把这次的勾选重放上去，所以每天 9 点的自动任务和网页同时改同一天也不会互相覆盖；自动任务写文件时同样应该保留 `done`、`doneAt` 和 `source: "me"` 的条目。

| 路径 | 内容 |
| --- | --- |
| `data/days/` | 每天一份任务和勾选 |
| `data/site.json` | 标题、仓库、课程文件夹路径 |
| `data/vault.json` | 加密后的编辑授权（第一次设置后生成） |

## 本地开发

需要 Node.js 18 以上，无任何依赖。

```sh
npm test              # 单元测试
npm run dev           # 预览 http://127.0.0.1:4181
npm run mock          # 带模拟 GitHub 的预览，打开 http://127.0.0.1:4181/?mock
```
